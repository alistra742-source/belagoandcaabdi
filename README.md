# Dataset Shards

This repository contains organized image-dataset shards under [`dataset/`](dataset/). The first shard is sourced from the Open Images validation set and uses one folder per class, a manifest, and source/licensing information.

Open Images contains approximately 9 million images across more than 20,000 classes, which cannot fit safely in a GitHub repository. This repository therefore starts with a manageable sample; future shards can be added separately.
