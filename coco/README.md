# COCO dataset source

The complete COCO 2017 corpus is not copied into this Git repository because it is approximately 25 GB for the image dataset alone, plus annotations, and would exceed practical GitHub repository limits. Use the official source links below to download it directly.

## Official source

- [COCO dataset home](https://cocodataset.org/)
- [COCO 2017 train images](http://images.cocodataset.org/zips/train2017.zip)
- [COCO 2017 validation images](http://images.cocodataset.org/zips/val2017.zip)
- [COCO 2017 test images](http://images.cocodataset.org/zips/test2017.zip)
- [COCO 2017 train/validation annotations](http://images.cocodataset.org/annotations/annotations_trainval2017.zip)
- [COCO 2017 test annotations](http://images.cocodataset.org/annotations/image_info_test2017.zip)

COCO contains 80 object categories with detection, segmentation, keypoint, and caption annotations. Download the archives from the official source, verify their checksums if provided by the source, and keep the original COCO license and attribution information.

The Open Images shards in this repository are separate from COCO and use their own per-image manifests.
